# lmv

CLI that opens local markdown files in a browser viewer. Bun + React 19 + Tailwind v4.

- **Vocabulary**: before exploring code, read `GLOSSARY.md` and the `docs/adr/` entries for the area, and name things with glossary terms (`docs/agents/domain.md`).
- **Gate**: finish with `bun run check` passing; it is the full CI gate (lint with warnings as errors, type check, tests).

## Pointers

- **Writing or reviewing code**: `CODING_STANDARDS.md`.
- **Changing a feature**: `docs/agents/navigation.md` maps each area to its files and checks.
- **Issues and triage**: `docs/agents/issue-tracker.md` and `docs/agents/triage-labels.md`.
